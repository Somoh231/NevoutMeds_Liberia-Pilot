# Pilot intake form

Fill this in with the owner before onboarding. **Collect only what is listed here.**

**Do not collect:**
- passwords;
- national ID numbers;
- bank or card details;
- licence numbers (these are optional in Settings and never required);
- any customer or patient information.

Keep the completed form with the pilot agreement. Don't paste it into group chats.
